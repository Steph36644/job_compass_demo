# 求职罗盘 V2.0 公开演示说明

状态：当前公开演示以私有仓库 `main`（`de4a9ef`，2026-10-14，V2.0 P0–P3）的产品行为为参照。本文只描述公开仓库里能安全运行的部分，不含密钥、生产项目地址或个人投递记录。

V1.0 / V1.1 文档仍保留在 `docs/` 与 `v1.1/`，仅作历史记录。

## 访客怎么用

应用目录是 `v1.0/job-compass`。不配置环境变量时：

- 看板、投递、简历、洞察和「载入示例数据体验」都在浏览器本地运行。
- 登录页说明尚未配置 Supabase，不会崩溃。
- `/api/auth/session` 返回 `configured: false`。
- AI 与云同步接口要求登录；未登录时返回固定中文提示，本地台账继续可用。

要使用账号或云端，请自建 **另一个** Supabase 项目，把 `.env.example` 复制为 `.env.local`，只填写公开的 URL 和 anon key。供应商 Key 只放在服务端变量 `JOB_COMPASS_AI_API_KEY`，不要写成 `NEXT_PUBLIC_`。不要把生产项目或服务端私钥写进这个公开仓库。

云端表使用 `supabase/migrations/001_public_demo_snapshot.sql`：一行一个用户、RLS 限制为 `auth.uid()`。这是公开演示的快照表，不是私有仓库 migration 原文。

## 有意不包含的内容

- 本机 Agent 数据层，以及任何个人快照、简历原件、JD 截图。
- 私有仓库的 git 历史。
- 生产环境变量和真实供应商 Key。

## 接口（未配置或未登录）

| 方法 | 路径 | 未登录时 |
| --- | --- | --- |
| GET | `/api/auth/session` | `{ configured: false, user: null }`（未配置时） |
| GET | `/api/ai/status` | 401，请先登录 |
| POST | `/api/ai/chat` | 401，请先登录；已登录但服务端没有 Key 时提示暂时无法调用 AI |
| POST | `/api/cloud/sync` | 401，请先登录 |
| GET | `/api/cloud/import` | 401，请先登录 |

浏览器提交供应商字段会被拒绝。AI 上游只允许 `api.openai.com`、`api.deepseek.com`、`dashscope.aliyuncs.com`。
